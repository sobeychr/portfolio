# Website-Lite

Since my termination at Aylo, I no longer have access to the codebase. Although, I am able to reproduce on a small scale the platform upgrade on my private Github. I run tests that demonstrate the potential of the upgrade compared to Aylo’s current platform with Lighthouse and Chrome’s Dev Tool.

* The performance score improved from below 40% to above 75%. Other websites using such technologies can go above 90%.
* Blocking time was entirely cut, compared to nearly 900ms.
* The speed index improved from over 5 seconds to almost 0.5 seconds.
* DOM content was loaded from nearly 2 seconds to almost 200 ms.
* Loading time was cut from nearly 3 seconds to almost 400 ms.
